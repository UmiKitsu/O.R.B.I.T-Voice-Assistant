# Local Orbit wake-word resources

The ONNX files and `tokens.txt` are from the Apache-2.0 licensed
`sherpa-onnx-kws-zipformer-zh-en-3M-2025-12-20` release.

Orbit uses the chunk-16 int8 encoder and joiner, the recommended fp32 decoder,
and one local CPU inference thread. Audio processed by the detector remains in
memory and is not written to disk.

`keywords.raw.txt` contains the standard `ORBIT` entry at boost `1.8` and
threshold `0.22`, plus the Filipino-English-friendly `OR BIT` entry at boost
`2.0` and threshold `0.18`. Both lines in `keywords.txt` were generated by the
official sherpa-onnx 1.13.4 `text2token` implementation using the matching
`phone+ppinyin` tokens and `en.phone` lexicon. Do not hand-author their phoneme
sequences.

The primary keyword detector is followed by a bounded, local Whisper Small
fallback when hybrid wake recognition is enabled. Candidate PCM remains in
memory; Whisper's application-temporary WAV is deleted after processing.
Neither transcripts nor audio are written to operational logs.

`model-manifest.json` records the fixed upstream archive, tokenizer, generated
entries, and checksum. `npm run setup:wake-word` verifies every packaged runtime
resource before a build.
